TELEGRAM EXCEL ROW SPLITTER BOT

1) Kompyuterga Python 3.11+ o'rnating:
   https://www.python.org/downloads/
   O'rnatishda "Add Python to PATH" ni belgilang.

2) Ushbu papkani oching.

3) .env.example faylidan nusxa oling va nomini .env qiling.

4) .env ichidagi:
   TELEGRAM_BOT_TOKEN=...
   qatoriga BotFather bergan tokenni yozing.
   Tokenni hech kimga yubormang.

5) Papka ichida CMD/Terminal oching va:
   pip install -r requirements.txt

6) Botni ishga tushiring:
   python bot.py

7) Telegramda botni oching va /start yuboring.

8) Excel'da masalan B2:B11 ni belgilang:
   Ctrl+C
   Telegram bot chatiga o'ting:
   Ctrl+V
   Send

Natija:
Har bir Excel qatori alohida Telegram xabari bo'lib yuboriladi.

Botni to'xtatish:
Ctrl+C

ESLATMA:
CMD oynasi yopilsa bot ham to'xtaydi.
24/7 ishlashi uchun keyin botni serverga/hostingga joylashtirish kerak.
